## 项目简介

Toolbox 是一个以静态网页形式呈现的在线工具与资源导航，将收录站点按用途整理为十七个分类，同一分类内再按相近用途连续排列，方便按场景浏览查找。

页面无需注册或安装，打开即可浏览全部分类或直接搜索站点，点击卡片在新标签页打开目标网站。

## 功能概览

- 分类导航：收录站点按用途分为十七个分类，同一分类内按相近用途连续排列。
- 站点搜索：按站点名称、描述、域名或分类名称实时筛选，并显示匹配数量。
- 目录联动：点击分类目录跳转到对应分类，滚动页面时目录自动高亮当前分类。
- 移动适配：窄屏下分类目录变为横向排列，站点卡片切换为单列显示。

## 使用方式

访问 <https://toolbox.krelinnbios.com> 即可开始使用，无需注册或安装；推荐使用现代桌面或移动浏览器。

1. 在搜索框输入站点名称、用途或域名，实时筛选并显示匹配数量；清空关键词可恢复完整列表。
2. 点击分类目录（手机端为横向分类栏）跳转到对应分类，继续滚动可浏览其他分类。
3. 点击站点卡片，在新标签页打开目标网站。

## 隐私与数据

- 本地处理：搜索、筛选和排序均在浏览器本地完成，输入的关键词不会发送到任何服务。
- 访问统计：站点通过 VibeCafé 统计脚本上报页面浏览事件，内容仅包含随机访客标识和事件类型，不包含搜索词或浏览内容，也不使用 Cookie；浏览器启用“请勿跟踪”或“全局隐私控制”时不会上报。
- 跳转访问：站点卡片直接指向目标网站，不经过中间跳转页面；目标网站的数据处理由其自身隐私政策说明。
- 第三方资源：站点图标通过 Google 图标服务加载，会向该服务发送目标站点域名；页面字体通过 Google Fonts 加载。

## 内容边界

- 站点名称与描述由本项目整理，仅说明主要用途；与收录站点及其运营方无隶属关系，收录不代表推荐。
- 站点可用性和服务质量由各站点运营方负责，本项目仅提供导航链接。
- “订阅服务”分类中的部分链接包含邀请码或推广参数，使用前请自行确认服务内容、价格和适用条款。
- 使用第三方站点时，请遵守对应站点的服务条款和使用规范。

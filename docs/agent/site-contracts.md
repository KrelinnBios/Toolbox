# 静态资产、滚动定位、数据结构与无障碍交互

此文件是项目内部的专项维护规则。根目录 [AGENTS.md](../../AGENTS.md) 仍然适用。

## 关键约束

### 静态资源版本控制

所有静态资源（CSS、JS、favicon）在 HTML 中引用时必须带版本参数：

```html
<link rel="stylesheet" href="./toolbox.css?v=202609091">
<script src="./sites.js?v=202609091" defer></script>
<script src="./toolbox.js?v=202609091" defer></script>
```

修改 CSS 或 JS 文件后，必须更新所有相关版本号：

- 格式：`YYYYMMDDX`（年月日 + 当日序号）
- 同一天的多次修改递增序号（1, 2, 3...）
- 确保 HTML 中所有对该文件的引用都更新版本号

### 滚动条样式

项目已实现符合 RepoRules WEB.md 规范的自定义滚动条（`toolbox.css` 第 1-67 行），包括：

- 6px 宽度
- 透明轨道
- 999px 圆角（胶囊形）
- 隐藏箭头按钮
- hover 和 active 使用同一主题色

**不要删除或修改滚动条相关样式**，除非用户明确要求。

### 站点数据结构

`sites.js` 中的站点数据必须遵循以下结构：

```javascript
const siteCategories = [
  {
    id: "category-id",        // 唯一标识符，kebab-case
    label: "分类名称",         // 显示给用户的中文名称
    items: [
      {
        name: "站点名称",      // 简短的站点名称
        url: "https://...",   // 完整 URL，必须包含协议
        desc: "站点描述",      // 用于搜索和帮助用户识别用途
        group: "用途小组"      // 同一分类内的内部归组字段，不直接显示
      }
    ]
  }
];
```

同一大分类内，定位相近的站点使用 `group` 字段归组。页面不显示小组标题，只让同组站点连续排列，并按中文拼音或英文名称排序。

### 目录与滚动定位

- 桌面端左侧目录固定在视口左侧，移动端使用横向目录栏
- 点击分类目录时滚动到右侧对应分类，不隐藏其他分类
- 右侧滚动时，以视口高度约 `2/5` 的位置判断当前分类并高亮左侧目录
- 滚动到页面底部时，高亮最后一个分类
- 搜索时保留完整目录，目录点击会清空搜索并恢复完整内容

### 无障碍要求

- 保持现有的语义化 HTML 结构（`<aside>`, `<main>`, `<section>`）
- 保留 ARIA 标签（`aria-label`, `aria-labelledby`, `role`, `aria-live`）
- 搜索框必须有 `<label>` 关联
- 交互元素必须可键盘访问
- 隐藏内容使用 `hidden` 属性，而非 `display: none`

### 搜索和排序

搜索逻辑在 `toolbox.js` 中实现：

- 实时搜索站点名称和描述
- 大小写不敏感
- 支持站点名称、描述、域名和分类名称匹配
- 搜索无结果时显示提示
- 实时更新显示的站点数量
- 同一分类内先按 `group` 分组，再按中文拼音或英文名称排序

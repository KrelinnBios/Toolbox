# 不用框架与构建工具的已定设计选择

此文件是项目内部的专项维护规则。根目录 [AGENTS.md](../../AGENTS.md) 仍然适用。

## 已确立的决定

### 为什么不使用构建工具？

项目足够简单，使用构建工具会增加复杂度而无明显收益。直接编辑源文件后推送到 GitHub，Cloudflare Pages 自动部署，流程简洁高效。

### 为什么不使用前端框架？

项目只需要简单的搜索、筛选和渲染，原生 JavaScript 完全够用。引入 React/Vue 会增加体积和加载时间，降低性能。

### 为什么使用 `defer` 而不是 `async`？

`defer` 保证脚本按顺序执行，`sites.js` 必须在 `toolbox.js` 之前加载。`async` 会导致执行顺序不确定。

### 为什么站点描述有些是英文？

部分站点本身就是英文网站，保留原始描述有助于用户识别。描述主要用于搜索匹配，而非完整翻译。
